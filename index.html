Technology

World-Action Model 技术架构

以统一表征连接观察、未来世界状态与可执行动作。

  1. Cross-Embodiment Data Curriculum：以跨机器人本体的数据课程组织学习过程。
  2. Unified Understanding–Generation–Prediction：在统一框架中协同世界理解、未来生成与动作预测。
  3. World-Action Model：连接世界状态建模和机器人动作生成。
  4. Hybrid Linear Temporal Memory：面向连续时序信息的混合线性记忆机制。
  5. 系统协同设计：围绕高效边缘部署统筹模型与运行系统。
